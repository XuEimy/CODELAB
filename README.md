# CODELAB v3 — 五模式多人协作游戏共创

## 五大模式
1. **🎮 游戏模式** — 全屏游戏体验，带浮动聊天和排行榜
2. **👥 共创模式** — 在线成员、贡献统计、AI 助手、游戏预览
3. **💬 规划模式** — 团队聊天、备忘录、任务清单
4. **🎨 设计模式** — 响应式预览（桌面/平板/手机）、设计笔记、配色工具
5. **⌨ 开发模式** — 代码编辑器 + 实时预览，双栏布局

## 用法
1. 安装 Node.js 18+
2. 解压 ZIP
3. 把 `.env.example` 复制为 `.env`，填入 API_KEY
4. 房主电脑运行：
   ```bash
   npm install
   npm start
   ```
5. 房主浏览器打开启动日志里显示的本机地址，默认是 `http://localhost:3000`，如果该端口被占用会自动顺延到下一个可用端口
6. 同一局域网内的其他人不要各自部署，直接访问房主电脑启动日志里显示的 `LAN access` 地址，例如 `http://192.168.43.7:3000`
7. 进入房间后点击顶部房间码可复制邀请链接，或点击“局域网”按钮复制局域网邀请链接

## 局域网联机说明
- 只需要一台电脑作为房主启动服务。
- 其他协作者只要和房主在同一个局域网，打开房主地址即可加入同一房间。
- 远程光标、代码同步、聊天和任务清单都走同一个房间同步通道。
- 如果你把浏览器开在 `localhost`，程序也会优先生成局域网可用的邀请链接，不会再把 `localhost` 发给别人。
