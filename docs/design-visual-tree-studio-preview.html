Design Workspace v2

让设计从智慧树和游戏概览开始，设计 Agent 与验证窗口只围绕当前节点展开

这张新网页按照 PRD v2 收口成 4 个核心角色：左边是 游戏概览，中间是 智慧树，右边是 设计 Agent。下面的验证区收成 设计预览 / 游戏预览 两个窗口，只围绕当前节点出现。

主入口不是参数表 先点树里的节点，再围绕节点共创、聊天、精修。
不相关就不展示 当前节点没有对应的精修项，就不强行塞一个假窗口。
验证区独立出来 设计预览和游戏预览不再混进任务拆解里，而是作为单独验证窗口承接结果。
