多窗口设计工作台

设计工具不再塞成一个大窗，而是按设计师工作流拆成 4 个协作窗口

这版预览专门验证两件事：第一，结构树、结构关系图、参数检查器和 Vibe Skills 是否应该分开；第二，是否能根据不同游戏自动换成对应 schema。 你可以直接切换 贪吃蛇、植物防守、平台跳跃， 也可以点 无 schema 看看系统是不是会真的把游戏专属窗口隐藏掉。

为什么拆窗 设计师先看结构，再选对象，最后精修参数。Vibe 不是普通参数，所以它应该独立成一个像 skills 一样的能力窗。
删掉假能力 没有 schema 就隐藏游戏专属窗口，不做假树、假参数。这样不会把系统做成“看起来很强，实际全是硬编码”。
