# CODELAB README 重构设计

## 目标

将 README 从“图片和说明连续堆叠”的状态，整理成一条面向两类读者的阅读路径：先让访客理解产品并进入在线体验，再让开发者快速完成本地运行与局域网协作。

## 读者与优先级

1. **产品访客与潜在协作者**：在首屏理解 CODELAB 的价值，看到在线体验入口、协作理念和真实产品界面。
2. **开发者**：在看过产品后，能立即找到安装、运行、配置与局域网协作说明。

采用“产品优先”而非“文档优先”或“两个入口并列”的结构。这样既保持公开项目页的吸引力，也不牺牲实际使用说明。

## 最终信息架构

1. **项目头部**
   - 项目名称与一句定位。
   - 在线体验链接。
   - 协作模型图 `docs/assets/collaboration-model.png`。
   - 紧凑的“开始使用”导航，分别链接到在线体验和本地运行章节。

2. **产品展示**
   - “在线演示”图：`live-demonstration.png` 全宽展示。
   - “系统设计”图：`system-design-overview.png` 与 `system-design-features.png` 依次展示，并配一句说明。

3. **工作流**
   - 默认展示 `workflow-overview.png`，作为从协作到成果的总览。
   - `workflow-01.png`、`workflow-02.png`、`workflow-03.png` 放入 GitHub 支持的 `<details>` 折叠区，确保全部素材保留，但避免 README 首屏过长。

4. **本地运行**
   - 保留 Node.js 版本、`npm install`、`npm start` 与本地访问地址。
   - 环境变量只说明变量名和用途；示例值使用 `your-api-key`，不展示看似真实的密钥前缀。

5. **局域网协作与项目背景**
   - 保留“一台主机、同一局域网加入”的操作要点。
   - 用一段简短文字说明项目适合独立游戏团队与 Game Jam 场景。

## 删除与保留

- **删除**：现有“## 五种模式”及其 5 行表格；它与系统设计图和产品展示重复，且缺少使用情境。
- **保留**：所有 7 张来自“多人”文件夹的产品图、协作模型图、在线体验链接、快速开始、局域网协作和项目背景。
- **不新增**：新的运行时功能、外部依赖、构建步骤或敏感配置。

## 内容与版式规则

- 每个产品图片区都由简短中文标题和一句用途说明引导，避免连续无说明的大图。
- 主图最多两张连续出现；工作流分步图折叠展示。
- 使用标准 Markdown、HTML `<details>` 和已有仓库相对路径，确保 GitHub README 与 Pages 环境都能正确渲染。
- 保持中文为主，英文只在代码命令、文件名和既有图中文字中出现。

## 验证方式

1. `git diff --check` 无格式错误。
2. README 所有本地图片路径均存在，图片数量为 8（协作模型图 1 张 + 产品展示 7 张）。
3. README 不再包含“## 五种模式”标题或原表格。
4. GitHub 上的 README 能正常显示图片、折叠工作流和在线体验链接。
